## 一句话

**WinUI 3** 写的 Windows DSH 启动器（README 自称 AnotherDSHL），
一条命令都不敲也能把 DSH 跑起来：选工作区、配 Node.js、启动、装插件、装整合包、换实例。

## 它解决什么问题

官方形态是「装 Node、跑 `dsh web`、开浏览器」，另外还能装官方桌面客户端。
ADL 把这三种启动方式放进同一个窗口，并且**不要求你先装 .NET 或 MSIX**
（发布版自带应用运行时），把 Windows 上的起步门槛压到「下载 → 装 → 点」。

## 三种启动方式（README 原话的意思）

| 方式 | 做法 |
| --- | --- |
| **常规版** | 在「工作区」选目录并配置 Node.js，再从首页启动 Web 服务 |
| **桌面版** | 首页右上角切换启动方式，按提示安装或启动**官方 DSH 客户端** |
| **整合包** | 在侧栏浏览市场，下载并安装后，从首页左上角选择实例启动 |

## 功能面（README 的表格）

- **启动与环境**：Web 服务启停、运行状态识别、工作目录、Node.js 选择、DSH 版本锁定、自定义端口；
- **桌面客户端**：官方客户端检测、下载安装、**签名校验**、启动与手动选择程序；
- **插件**：官方与社区目录、搜索与筛选、详情、安装、已安装列表、自定义目录源。

## 环境要求（README）

- 系统：**Windows 10 19041+ / Windows 11，x64**；
- **Web 启动与整合包操作**需要 Node.js **22.19+ 或 24+**；普通插件安装还需要 `pnpm`；
- 整合包安装在缺少可用 `pnpm` 时，会为实例准备专用版本；
- 首次获取 DSH、插件与依赖**需要联网**；README 强调 API 密钥保存在 DSH 侧（不是启动器里）。
