## 一句话

**从 MC 启动器借交互**的 Windows 桌面启动器（Electron + React），
核心概念是**整合包 = 一套真隔离环境**：DSH 版本 + 插件 + 技能 + 预设 + 配置 + 会话都在里面，
互不串扰、随点随切，也能把整包发给别人导入即启动。

## 它解决什么问题

DSH 的插件、技能、预设、配置、会话是分散在几个目录里的，想让「工作用的一套」和「尝鲜的一套」
并存，手工隔离很容易出错。它把「一套环境」做成一个可以新建、切换、导出、发给别人的**对象**——
这正是 MC 整合包的做法。首启还会自动带入「官方默认整合包」（DSH 本体 + Web 全家桶界面 +
Office 文档技能 + AI 去味写作技能），所以它追求的是**下载一个 exe 就能开始用**。

## 怎么用（README）

- **整合包页**：新建 / 切换 / 删除整合包；删除改成了**原子回收站**——服务还挂着时整体失败并明确报错，
  不会出现「记录还在、环境没了」的半删状态；
- **官方整合包按版本可选**：顶部有「官方整合包」堆叠入口，展开是所有历史版本
  （最新标「推荐」，每行写着**适配哪个 DSH 版本**与体积）；
- **内置 DSH Market / 技能市场**：不用翻 GitHub、不用手敲 `dsh plugin add`；
- **快照式导出 / 导入**：把整包连插件本体、依赖、技能、配置打成 zip；
  导出前**自动剔除 API Key、会话记录等个人数据**，绝对路径自动改写；
  对方导入即可启动，**全程不联网重装依赖**；
- **上游关系**：它是 [rirko/dsh-melody-launcher](https://github.com/rirko/dsh-melody-launcher)
  的 **C 端分支**（README 明确标注）。
