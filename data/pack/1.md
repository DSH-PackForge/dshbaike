## 一句话

**它是一个「换个更顺手的 Web 界面」的通用增强包**，不是编码包也不是玩梗包：9 层 bundle 里除了两个出厂 bundle 和装卸工具 [[plugin/2]]，剩下 6 个全是界面/交互增强（流式输出、皮肤、任务看板、上下文洞察、底栏、鲸鱼桌宠），再加 20 个 skill。

## 成分表

| # | bundle | 在包里干什么（据包名与包描述） |
| --- | --- | --- |
| 1 | `@deepseek-ai/dsh-base` | 出厂基座，所有包的第一个 bundle |
| 2 | `@deepseek-ai/dsh-web-app` | 出厂 Web 面 |
| 3 | `@dsh-packforge/dsh-pack-plugin` | 包管理插件（[[plugin/2]]） |
| 4 | `dsh-plugin-whale-pet` | 小鲸鱼桌宠 |
| 5 | `dsh-smooth-stream` | 让流式输出更「丝滑」 |
| 6 | `@linxin666/dsh-client-ui-task-board` | 任务看板 |
| 7 | `dsh-bottom-info-bar` | 底部信息栏 |
| 8 | `dsh-myskin` | 自定义皮肤（走 `--dsw-*` 设计令牌） |
| 9 | `dsh-context` | 上下文洞察与图表 |

**bundle 与 dependency 是两份清单**：`bundles` 决定装配顺序，`dependencies` 决定装哪个版本。这个包 9 个 bundle、7 个依赖——两个出厂 bundle 不是依赖项（它们的来源是安装目录），所以数目对不上是正常的，机制见 [[tutorial/3]]。

## 它的 patch 层：本站相对市场页的增量

manifest 里带一段完整的 `patch`，也就是这个 profile 的用户补丁层（机制见 [[concept/1]]）。它顺手做了几件市场页不会告诉你的事：

| 目标行 | 写成什么 |
| --- | --- |
| `agent-default-model` | `provider: deepseek-account`、`model: deepseek-flash`、`reasoningEffort: high` |
| `ui-settings` | `config.enabled: false`（**不是** `disabled: true`，见 [[recipe/1]]） |
| `ui-chat` | `transcriptView: standard`、`performanceUsage: compact` |
| `ui-settings-account` | `version: 1`、`step: done`、`usage: compact`、`developerTools: false` |
| `dsh-myskin` | `enabled: true` 加一整组 `--dsw-*` 令牌（亮暗各一套） |

换句话说：**装完这个包，你的默认模型、思考强度、聊天记录视图、设置页的账号表单都会被它改掉**。这是「整合包 = 一整套配置」最直白的例子。

## 兼容性与安装端

- **DSH 版本：未声明**。manifest 的 `dshVersion` 是空串，也没有 `dshVersions` 字段。按 [[spec/2|规范仓库]] 的规则，缺省不会拦住安装（回落到本机已装版本），但**没有任何兼容性承诺**——这是这个包最需要留意的一点。
- **启动器声明：全式四项全 true**（`dshl`、`hdsl`、`dsh-packforge-app`、`official-desktop`）。本站市场里用全式的只有它一条，见 [[launcher/2]]。
- **形态**：`profile`。装完落在一个 profile 目录里，见 [[concept/2]]；卸载/回滚走 profile 侧的那套办法。

## 本机实测：20 个 skill 与一个空的预设目录

本机的「切包」是用 junction 做的：`~/.dsh/skills` 与 `~/.dsh/.agent-presets` 都指向 `.dsh-pack/` 下的暂存目录，`.dsh-pack/migrate.log` 里能看到 `switch done: active=<包名> method=junction` 这类行（实测 2026-10-02）。

对准当前激活的这个包看：**skills 暂存目录里有 20 个条目**（19 个 `dsh-` 前缀加 `knotlink`），与包描述里「添加 20 个 skill」的数目一致；**同名的 agent-presets 暂存目录是空的**。也就是说：这个包带技能，**不带预设**。
