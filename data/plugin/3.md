## 它解决什么问题

DSH 默认的交互入口是浏览器界面（[[client/1]]）或裸命令行。**dsh-TUI 补的是第三种：常驻终端的一套完整界面**——会话、工具调用、思考流、状态与提示都做进终端里，不用来回切窗口。

它的定位在与仓库同龄的生态里算罕见：**star 3957**（本轮实测，2026-10-03），是这个生态里被收藏最多的第三方插件之一；作者 ccch1mneyyy 同时也是社区互操作规范 [[spec/1]] 的联合发起方之一（dsh-TUI 团队的署名就出自那里）。

## 它提供什么（照它的 README）

- **像素鲸鱼宠物**：三种出场动画，点一下会醒；第一个任务开始后冻住不打扰；
- **启动页与首次向导**：每次启动落在带**真实输入框**的落地页；首次运行走四步向导（API key / 语言与主题 / 模型与工作区 / 快捷键），随时用 \`/setup\` 重跑；
- **终端原生界面**：流式 Markdown、工具卡、\`/\` 与 \`@\` 补全；
- **实时工作状态与流式思考**：能看到它正在干什么，而不只是转圈；
- **双击 Esc 回退时间**：把会话倒回上一次输入之前（README 的叫法是 time rewind）；
- **上下文进度条与 TPS 表**：一眼看出上下文用了多少、每秒出多少 token；
- **纯插件挂载**：README 的说法是"不改核心、装上即生效、卸载不留补丁"。

## 怎么装（照抄它的 README）

\`\`\`bash
npm install -g @deepseek-ai/dsh @deepseek-harness-tui/dsh-tui
\`\`\`

它随包提供 \`dsh-tui\` 命令（\`dsh-tui version\` / \`dsh-tui help\` 在没有 DSH 安装时也能跑）。**注意 README 明确说了 Git URL 安装不行**（"Git URL installs are not …"），要走 npm registry 包——所以别用 \`dsh plugin add github:ccch1mneyyy/dsh-TUI\` 那种写法。
