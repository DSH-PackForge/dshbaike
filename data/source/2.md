## 它是什么

DSH 整合包（`.dspack`）的**索引与分发入口**。它自己不做界面也不做评审：把作者发在 GitHub Release 上的 `.dspack` 汇总成一份公开、可机器读的数据接口，顺带把「哪些插件值得整合包作者装」这件事以两份精选清单的形式发表出来。

按 [index/index.md](https://github.com/DSH-PackForge/DSH-PackForge/blob/main/specs/index/index.md) 的契约（`schemaVersion: 2`），索引是刻意做薄的：`index.json` 只放指针与元数据，**完整 manifest 与 README 按 `packs/<owner>.<repo>/` 懒加载**。这是本站能只取用、不复制的原因之一。

## 三份清单的口径不一样

同一个市场里，「插件」这个词出现在两个地方，别混：

- **`plugins.json`（4 条）** 是**精选推荐清单**，回答「整合包作者该装哪几个」；每条给 `id` / `name` / `url` / `category`（zh + en）/ `description`（zh + en）/ `install` / `badges`。
- **各包 `manifest.json` 的 `bundles` + `dependencies`** 是**实际构成**，回答「这个包里到底有什么」。本站的插件词条收录门槛正是从这两处反查出来的（`usedInPacks`）。

同一个包名可能只在其中一处出现。举个正例与一个反例：

- [[plugin/2]] 两处都在：精选清单里有它，两个包的 `dependencies` 里也有它。
- [[plugin/3]] **只在精选清单里**：8 个包的 `bundles` / `dependencies` 里都找不到它——因为它是给包作者用的工具，不是被包引用的层。

## 发布与收录

发布契约在 [publishing/v1.md](https://github.com/DSH-PackForge/DSH-PackForge/blob/main/specs/publishing/v1.md)：把仓库做成 public、打上约定的话题、发**正式 Release**，并把 `.dspack` 与 `.sha256` 侧车一起挂上去。索引随之更新（无变化就跳过提交）。本站读的是同一份索引，所以**包作者按契约发布一次，两边都能收录**。

另外两条规范文档与它直接相关：[manifest/v5.md](https://github.com/DSH-PackForge/DSH-PackForge/blob/main/specs/manifest/v5.md)（清单里 `bundles` + `dependencies` 钉死版本、`type` 分 `profile` / `dshhome`）与 [pack-structure/v3.md](https://github.com/DSH-PackForge/DSH-PackForge/blob/main/specs/pack-structure/v3.md)（`.dspack` 容器布局）。**说明**：本机 checkout 的 `specs/` 目录下只有一个 `workspace-config/v1.md`，上述规范文件本轮只能按公开仓库路径引用，未能读到本地副本。

## 未核实 / 未声明

- **许可**：未声明——本轮没有读到市场仓库的 LICENSE 或 package.json 里的许可字段，不猜协议。
- **索引发布地址**：本页 `linkOut` 写的是 `https://dsh-packforge.github.io/dsh-pack-market/index.json`（来自 `data/sources.yml` 的登记与包 README 里的徽章域名），**本轮未实测拉取该 URL**；核实过的是本地账本快照。
- **索引更新频率**：只核实到「每轮生成」（`generatedAt` 是生成时间戳），触发方式与调度周期未核实。
- **`dshhome` 形态的实包**：8 个包全是 `type: profile`，没有任何 `dshhome` 样本，所以「整机形态在市场上长什么样」本轮无事实可写。
- **下载量的统计口径**：`stats.json` 标 `source: github-releases`，取的是 Release 资源的下载计数；是否去重、是否含镜像与自动化拉取未核实。
- **site 上的下载量快照时间**：`stats.json` 的 `generatedAt` 是 `2026-09-30`，与索引同批生成；本页表格标的是账本快照日期 `2026-10-01`。
