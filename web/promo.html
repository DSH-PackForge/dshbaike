03

你大概是从这两条路进来的

想找具体东西 → 上面的搜索框；想搞懂 DSH → 左边三篇按顺序读

我刚接触 DSH，先读什么

按这个顺序读，三篇建立起「层」的心智模型，后面看什么都顺。

  1. 为什么 DSH 升级后插件会失效先知道「补丁是一层层叠上去的」，才知道为什么会断
  2. 装插件时到底发生了什么add 命令其实是 pnpm 转发器；搞清落点、构建授权与「装了没生效」
  3. 写一个 DSH 插件从零声明 bundle 与 patch 层，并说清它为什么不是普通 npm 依赖

我在找某个东西

三条路都通向同一批词条，只是入口不同。

  1. 按类型浏览全部词条概念 / 插件 / 教程 / 资源源，一次看全
  2. 从分区进十二个分区各自是一张清单 + 去源头的外链
  3. 看插件聚合页定位、关系、兼容与坑——不是把上游 README 抄一遍
